# InspireX OS UI/UX — Emerald Studio Direction

This pass follows the supplied visual references: near-black green-tinted surfaces, vivid emerald accents, subtle atmospheric glow, layered cards, compact labels, and restrained colored metric cards.

## Updated
- Global theme tokens shifted to a richer emerald/teal accent and green-tinted charcoal surfaces.
- Removed the default Vite root max-width/padding that could constrain the full app shell.
- Refined the application top bar, page content width, search trigger, and sidebar class hooks.
- Added distinct soft emerald and amber treatments to existing dashboard metric cards.
- Added visible keyboard focus and reduced-motion handling.

## Scope and verification
This is a visual styling pass. It intentionally does not change financial calculations, state management, or transaction workflows. Run `npm run build` and preview with `npm run dev` before deploying.
